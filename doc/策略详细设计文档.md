## Strategy_01: 稳健概率策略（已存在，详细补充）

### 核心公式

```
单选得分 = max(主胜概率, 主负概率) × (1 + P值)
熵 = -Σ(p × log₂p)，其中 p ∈ {主胜概率, 主平概率, 主负概率}
胜负差 = |主胜概率 - 主负概率|
```

### 详细选择规则

| 类型 | 选择指标 | 排序方向 | 投注方式 |
|------|----------|----------|----------|
| 全选(l) | 熵 | 降序 | 310 |
| 双选平(j) | 主平概率 | 降序 | 取主胜/主负中较大的 + 平 |
| 双选主客(k) | 胜负差绝对值 | 升序 | 30 |
| 单选(i) | 单选得分 | 降序 | 概率大的方向 |

### 参数建议

```
保守配置: i=6, j=2, k=0, l=1  (命中率优先)
平衡配置: i=5, j=2, k=1, l=1  (默认配置)
进取配置: i=4, j=2, k=2, l=1  (收益优先)
```

### 核心公式

```
冷门得分 = 主负概率 × (1 if P值 > 0.5 else 0.5)
```

### 详细选择规则

## Strategy_03: 期望价值策略

### 核心公式

```
期望价值(EV) = 赔率 × 概率 - 1

隐含概率 = 1 / 赔率
修正概率 = 隐含概率 / Σ隐含概率（归一化去抽水）
```

### 详细选择规则

| 类型 | 选择指标 | 排序方向 | 投注方式 | 阈值 |
|------|----------|----------|----------|------|
| 全选(l) | 胜负负EV方差 | 降序 | 310 | - |
| 双选平(j) | 平局EV且主平概率 | 混合 | 主/负大+平 | EV平 > 0.1 且 平率 > 0.25 |
| 双选主客(k) | 胜负EV绝对值之和 | 降序 | 30 | EV胜+EV负 > 0.2 且 胜负差 < 0.1 |
| 单选(i) | EV最大值 | 降序 | EV最大结果 | EV > 0.05 |

### 阈值建议

```
保守模式: EV阈值提高 50%
平衡模式: EV阈值 = 标准值
激进模式: EV阈值降低 30%
```

### 实现伪代码

```python
# 计算 EV
def calculate_ev(row, outcome):
    sp = row[f'主{outcome}SP值']
    prob = row[f'主{outcome}概率']
    return (sp * prob - 1) if sp > 0 else -999

# 选择逻辑
# 全选：选择 EV方差最大的（三方向EV差异大 = 不确定性高）
ev_columns = ['主胜EV', '主平EV', '主负EV']
df['ev_variance'] = df[ev_columns].var(axis=1)
```

## Strategy_04: 联赛回归策略

### 核心公式

```
偏差得分 = |真实频率 - 理论概率| × 置信度权重

置信度权重 = √(样本量 / 100) × (-log10(P值 + 0.001) / 1.3)

方向得分 = {
    '胜': (真实频率胜 - 理论概率胜) × 置信度权重,
    '平': (真实频率平 - 理论概率平) × 置信度权重,
    '负': (真实频率负 - 理论概率负) × 置信度权重
}
```

### 详细选择规则

| 类型 | 选择指标 | 排序方向 | 投注方式 | 筛选条件 |
|------|----------|----------|----------|----------|
| 全选(l) | 联赛P值 | 升序 | 310 | P值 < 0.1 |
| 双选平(j) | 方向得分_平 | 降序 | 主/负大+平 | 真实平 > 理论平 |
| 双选主客(k) | 方向得分绝对值之和 | 降序 | 30 | 任一方向得分 > 0.05 |
| 单选(i) | 方向得分最大值 | 降序 | 得分最大方向 | 得分 > 0.08 |

### 数据准备

需要从 `df_leagues` 获取：
- 样本量
- 理论概率_胜/平/负
- 真实频率_胜/平/负
- P值

### 实现关键点


## Strategy_05: 庄家抽水反选策略

### 核心公式

```
抽水率 = 1/胜赔 + 1/平赔 + 1/负赔 - 1

反向概率系数 = 1 + (抽水率 - 0.069) × 10  # 0.069为平均抽水

反选得分 = 原始概率 × 反向概率系数
```

### 详细选择规则

| 类型 | 选择指标 | 排序方向 | 投注方式 | 筛选条件 |
|------|----------|----------|----------|----------|
| 全选(l) | 抽水率 | 降序 | 310 | 抽水率 > 0.07 |
| 双选平(j) | 反选得分_平 | 降序 | 胜/负大+平 | 抽水率 > 0.065 |
| 双选主客(k) | 反选得分绝对值 | 降序 | 30 | 选择反选得分高的一方 |
| 单选(i) | 反选得分最小值 | 降序 | 反选得分最低的结果 | 抽水率 > 0.07 |

### 逻辑解释

```
高抽水 = 庄家认为市场情绪偏向某一方
反选 = 与庄家判断相反，投注市场不看好的方向
```

### 实现关键点

```python
# 高抽水赛事筛选
high_margin_matches = df[df['庄家抽水'] > 0.07]

# 计算反选得分（越低说明市场越看好，越可能是反向机会）
df['反选胜'] = (1 - df['主胜概率']) * (1 + df['庄家抽水'] * 5)
df['反选平'] = (1 - df['主平概率']) * (1 + df['庄家抽水'] * 5)
df['反选负'] = (1 - df['主负概率']) * (1 + df['庄家抽水'] * 5)
```

## Strategy_07: 熵最小化策略

### 核心公式

```
熵 = -[p胜×log(p胜) + p平×log(p平) + p负×log(p负)]

确定性得分 = -熵  # 熵越小，确定性越大
```

### 详细选择规则

| 类型 | 选择指标 | 排序方向 | 投注方式 | 筛选条件 |
|------|----------|----------|----------|----------|
| 全选(l) | 熵 | 降序 | 310 | 建议l=0或1 |
| 双选平(j) | 熵且主平概率 | 混合 | 主/负大+平 | 熵 < 1.1 且 平率 > 0.25 |
| 双选主客(k) | 熵且胜负差 | 混合 | 30 | 熵 < 1.0 且 胜负差 > 0.2 |
| 单选(i) | 确定性得分 | 降序 | 概率最大 | 熵 < 0.9 |

### 特点

```
熵 < 0.8  = 非常确定（强胆机会）
熵 0.8~1.1 = 比较确定
熵 1.1~1.4 = 不确定
熵 > 1.4  = 非常不确定
```

### 参数建议

```
超保守: i=7, j=1, k=0, l=1  (几乎不选不确定场次)
保守:   i=6, j=2, k=0, l=1

```

## Strategy_08: 赔率离散策略

### 核心公式

```
赔率方差 = Var([胜赔, 平赔, 负赔])

赔率离散度 = (赔率最大值 - 赔率最小值) / 赔率平均值

强胆识别 = 最小赔率 / 第二小赔率 < 0.7
```

### 详细选择规则

| 类型 | 选择指标 | 排序方向 | 投注方式 | 筛选条件 |
|------|----------|----------|----------|----------|
| 全选(l) | 赔率方差 | 降序 | 310 | 方差 > 2.0 |
| 双选平(j) | 平赔与其他差距 | 降序 | 胜/负大+平 | |平赔-其他| > 1.5 |
| 双选主客(k) | 赔率离散度 | 降序 | 30 | 离散度 > 0.3 |
| 单选(i) | 强胆识别 | 降序 | 最小赔率结果 | 强胆得分 > 0 |

### 实现关键点

```python
odds_cols = ['主胜SP值', '主平SP值', '主负SP值']
df['赔率方差'] = df[odds_cols].var(axis=1)
df['赔率离散度'] = (df[odds_cols].max(axis=1) - df[odds_cols].min(axis=1)) / df[odds_cols].mean(axis=1)

# 强胆识别
df_sorted = df[odds_cols].values
df['强胆得分'] = df_sorted.min(axis=1) / np.partition(df_sorted, 1, axis=1)[:, 1]
```

### 数据需求

需要额外维护各联赛的近期表现趋势，或从历史数据动态计算。

```python
# 模拟：从 df_matches 中计算最近N期趋势
def calculate_momentum(df, league, window=6):
    recent_matches = df[
        (df['赛事'] == league) &
        (df['比赛结果'] != '未知')
    ].tail(window)

    # 计算各类结果的加权频率
    weights = [0.4, 0.35, 0.25][:len(recent_matches)]
    outcome_freq = {
        '胜': sum(weights[i] for i, r in enumerate(recent_matches['比赛结果']) if r == '胜'),
        '平': sum(weights[i] for i, r in enumerate(recent_matches['比赛结果']) if r == '平'),
        '负': sum(weights[i] for i, r in enumerate(recent_matches['比赛结果']) if r == '负')
    }
    return outcome_freq
```

## Strategy_10: 蒙特卡洛模拟策略

### 核心公式

```
模拟次数 N = 10000

对每场比赛进行 N 次伯努利试验:
    随机数 r ∈ [0,1]
    if r < p胜: 结果 = '胜'
    elif r < p胜 + p平: 结果 = '平'
    else: 结果 = '负'

模拟胜率 = Σ(结果='胜') / N
模拟波动 = SimVar([胜率, 平率, 负率])

模拟得分 = 模拟胜率 - 实际概率
```

### 详细选择规则

| 类型 | 选择指标 | 排序方向 | 投注方式 | 筛选条件 |
|------|----------|----------|----------|----------|
| 全选(l) | 模拟波动 | 降序 | 310 | 波动 > 0.1 |
| 双选平(j) | 模拟平率-实际平率 | 降序 | 胜/负大+平 | 差异 > 0.05 |
| 双选主客(k) | 模拟胜负差 | 降序 | 30 | 差异 > 0.08 |
| 单选(i) | 模拟期望收益 | 降序 | 模拟最优结果 | 收益 > 0.05 |

### 实现关键点

```python
import numpy as np

def monte_carlo_simulate(probs, n=10000):
    """
    probs: [p胜, p平, p负]
    返回: {胜率, 平率, 负率, 波动}
    """
    cumulative = np.cumsum([0] + probs)
    randoms = np.random.random(n)

    results = np.zeros(n)
    for i, r in enumerate(randoms):
        if r < cumulative[1]:
            results[i] = 0  # 胜
        elif r < cumulative[2]:
            results[i] = 1  # 平
        else:
            results[i] = 2  # 负

    win_rate = np.mean(results == 0)
    draw_rate = np.mean(results == 1)
    loss_rate = np.mean(results == 2)
    fluctuation = np.var([win_rate, draw_rate, loss_rate])

    return {
        'sim_win': win_rate,
        'sim_draw': draw_rate,
        'sim_loss': loss_rate,
        'fluctuation': fluctuation
    }

# 应用于每场比赛
df[['模拟胜率', '模拟平率', '模拟负率', '模拟波动']] = df.apply(
    lambda row: pd.Series(monte_carlo_simulate(
        [row['主胜概率'], row['主平概率'], row['主负概率']]
    )),
    axis=1
)
```

## Strategy_11: 凯利公式策略

### 核心公式

```
f = (b × p - q) / b

其中:
    b = 赔率 - 1 (净赔率)
    p = 隐含概率 (去抽水后)
    q = 1 - p

凯利得分 = f × p  (同时考虑期望和概率)
```

### 详细选择规则

| 类型 | 选择指标 | 排序方向 | 投注方式 | 筛选条件 |
|------|----------|----------|----------|----------|
| 全选(l) | |f胜| + |f平| + |f负| | 降序 | 310 | - |
| 双选平(j) | f平且主平概率 | 混合 | 胜/负大+平 | f平 > 0.05 |
| 双选主客(k) | f胜 + f负 | 降序 | 30 | 和 > 0.08 |
| 单选(i) | 凯利得分 | 降序 | f最大结果 | f > 0.03 |

### 凯利公式解读

```
f > 0.05: 强烈推荐投注
f 0.02~0.05: 可以考虑
f 0~0.02: 边缘机会
f < 0: 不推荐投注
```

### 实现关键点

```python
def calculate_kelly(sp, prob):
    """
    sp: SP值
    prob: 隐含概率
    返回: f值
    """
    b = sp - 1  # 净赔率
    p = prob
    q = 1 - p
    return (b * p - q) / b if b > 0 else -999

# 计算各方向的f值
df['f胜'] = df.apply(lambda r: calculate_kelly(r['主胜SP值'], r['主胜概率']), axis=1)
df['f平'] = df.apply(lambda r: calculate_kelly(r['主平SP值'], r['主平概率']), axis=1)
df['f负'] = df.apply(lambda r: calculate_kelly(r['主负SP值'], r['主负概率']), axis=1)

# 凯利得分（f × 概率）
df['kelly_score胜'] = df['f胜'] * df['主胜概率']
df['kelly_score平'] = df['f平'] * df['主平概率']
df['kelly_score负'] = df['f负'] * df['主负概率']
```

## Strategy_12: 风险平价策略

### 核心公式

```
风险贡献 = 概率 × 方差

方差风险 = Var(概率分布)
    = p胜×(1-p胜)² + p平×(1-p平)² + p负×(1-p负)²

目标比例 = 1:1:1 (胜:平:负风险均衡)

当前比例 = (Σ风险_胜, Σ风险_平, Σ风险_负)

平衡得分 = |当前比例 - 目标比例| (越小越好)
```

### 详细选择规则

| 类型 | 选择指标 | 排序方向 | 投注方式 | 筛选条件 |
|------|----------|----------|----------|----------|
| 全选(l) | 风险贡献 | 降序 | 310 | 高风险场次 |
| 双选平(j) | 平风险缺口 | 降序 | 胜/负大+平 | 平风险 < 胜负平均 |
| 双选主客(k) | 风险平衡效果 | 降序 | 30 | 能平衡两类风险 |
| 单选(i) | 最小风险 | 升序 | 风险最小结果 | - |

### 实现逻辑

```python
# 计算每场比赛的风险贡献
def calculate_risk_contribution(prob):
    """计算某结果的风险贡献"""
    return prob * (1 - prob) ** 2

df['风险_胜'] = df['主胜概率'].apply(calculate_risk_contribution)
df['风险_平'] = df['主平概率'].apply(calculate_risk_contribution)
df['风险_负'] = df['主负概率'].apply(calculate_risk_contribution)

# 贪心选择算法
def risk_parity_selection(df, target_counts):
    """
    贪心算法选择使风险最均衡的组合
    target_counts: {i, j, k, l}
    """
    selected = []
    risk_sum = {'胜': 0, '平': 0, '负': 0}

    for _ in range(9):
        # 计算添加每场后的新平衡度
        balance_scores = []
        for idx, row in df.iterrows():
            if idx in selected:
                continue

            new_risk = {
                '胜': risk_sum['胜'] + row['风险_胜'],
                '平': risk_sum['平'] + row['风险_平'],
                '负': risk_sum['负'] + row['风险_负']
            }
            target_sum = sum(new_risk.values())
            balance_score = sum(abs(new_risk[k] / target_sum - 1/3) for k in ['胜', '平', '负'])
            balance_scores.append((idx, balance_score))

        # 选择使平衡度最好的比赛
        best_idx, _ = min(balance_scores, key=lambda x: x[1])
        selected.append(best_idx)

        # 更新风险总和
        row = df.loc[best_idx]
        risk_sum['胜'] += row['风险_胜']
        risk_sum['平'] += row['风险_平']
        risk_sum['负'] += row['风险_负']

    return selected
```
